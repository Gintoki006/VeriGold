The Problem We Solve

Lenders operate in silos. That's a systemic risk.

In India's ₹8 lakh crore gold loan market, a borrower can pledge the same gold ornament across multiple lenders simultaneously — and no institution is aware. There is no shared registry, no cross-lender visibility, no equivalent of a credit bureau for gold.

VeriGold resolves this gap. Lenders can verify borrower exposure across the network without accessing any other lender's data — not the loan amount, not the borrower identity, not the collateral details. Only a cryptographic confirmation of whether exposure exists.

Built on Trust, Not on Shared Secrets

Four layers of protection ensure no lender's private data is ever exposed, while every lender gets the risk signal they need.

HMAC-SHA256 Identity

Borrower Aadhaar is hashed with a server-side pepper. The plaintext never leaves the API call. Even we can't reverse it.

Hyperledger Fabric Ledger

Every pledge is recorded on a permissioned blockchain. No single lender controls the data. Tamper-proof, auditable, decentralized.

Hybrid AI Risk Engine

Rule-based scoring is authoritative. Gemini LLM adds natural-language insight — but can only escalate risk, never reduce it.

Zero-Knowledge Proof

Prove that total exposure is below a threshold — without revealing the actual exposure amount. Mathematical certainty, zero data leakage.

How VeriGold Works

Three steps. A risk decision is returned in under ten seconds — before any pledge is accepted.

01

Hash the Identity

Enter the borrower's Aadhaar. It's instantly HMAC-hashed — the plaintext is never stored, logged, or sent over the wire again.

02

Query the Registry

The hash hits Hyperledger Fabric. Active pledges, exposure buckets, velocity signals, and gold fingerprint matches — all returned in milliseconds.

03

Get Risk Decision

The deterministic rule engine scores exposure. The AI layer provides a structured narrative — every factor is logged and independently auditable.

Frequently Asked Questions

Borrower identities are never stored in plaintext. The Aadhaar number is HMAC-SHA256 hashed with a server-side secret key before any processing. The hash is one-way and irreversible. Additionally, zero-knowledge proofs allow exposure verification without revealing actual loan amounts.

Each gold item is characterized by its weight (quantized to 0.5g), purity (nearest karat), item type, dimensions, and an optional perceptual image hash. These attributes are canonicalized and SHA-256 hashed to create a unique fingerprint that can detect if the same gold is being pledged at multiple lenders.

VeriGold runs on Hyperledger Fabric — a permissioned, enterprise-grade blockchain. Unlike public chains, only enrolled and verified lender organizations can participate. There are no tokens, no gas fees, and no public exposure of transaction data. Lender identities are managed via Fabric CA with MSP credentials.

VeriGold returns HTTP 503 — it never fabricates, caches, or guesses a risk result. If the Fabric network is unreachable, the system explicitly tells the lender that verification is temporarily unavailable. Integrity over availability, always.
